# Xchange v3 Known Differences from v2

This document provides a single, comprehensive list of every deliberate, decided difference in behavior, responses, and data contracts between xchange v3 and v2.

- **Baseline SHA**: Measured at `origin/main` commit `3a23eb9` (2026-10-07).
- **Purpose**: Read once by the system owner prior to initial production release (#121 item C.3).
- **Automated Guard**: Guarded by `api/tests/known_differences_listed_test.rs` to ensure that every decided difference documented in `api/` source code comments and tests remains cited here and does not drift apart.

---

## Decided Differences

| Area / Topic | v2 Behavior | v3 Behavior | Decided By / Where | Source / Reference | Visibility / Caller |
|---|---|---|---|---|---|
| **RPC Envelope** · Malformed request body | Returned JavaScript engine error text in English (e.g. `SyntaxError: Unexpected token ...`) with status 400. | Returns 400 with domain Thai message `คำขอไม่ถูกต้อง` for non-JSON or JSON `null` request bodies. | Lane controller on T11e (#115) | `api/src/application/compat/envelope.rs:18-19`, `api/tests/compat_envelope_test.rs:16-18`, `api/tests/compat_envelope_test.rs:315` | No valid screen sends this (malformed HTTP callers). |
| **RPC Envelope** · Strict JSON parsing & formatting | JavaScript engine read a `\u` escape of half a surrogate pair, read numbers too large for a double, and read >128 levels of nesting. On the staff route, a name written as a fraction printed without trailing zeros (`1.0` -> `1`, and integers beyond 2^53 rounded). A payload written as text holding a letter of two UTF-16 units spread into one key per unit, with each value holding half a surrogate pair. | Answered with 400 `คำขอไม่ถูกต้อง` for what `serde_json` refuses: a `\u` escape of half a surrogate pair, a number too large for a double, or more than 128 levels of nesting. On the staff route, a name written as a fraction is printed as Rust prints (`1.0` stays `1.0`, integer beyond 2^53 is exact). A payload written as text holding a letter of two UTF-16 units spreads into one key per unit where each value is U+FFFD (Rust text cannot hold half a surrogate pair). | Lane controller on T11e (#115); #254 (PR 258) | `api/src/application/compat/envelope.rs:20-29` | No valid screen sends this. |
| **RPC Replay** · Replay harness difference tally (test harness) | Not a difference in v2 behavior (not in the recording); this file is the test harness that holds the other differences. | Replay harness counts and accounts for every step via `Tally` (replayed, known difference, excluded, applied behind); cited because it tallies decided difference steps. | T11a-0 (#156), T11e (#115) (test harness accounting) | `api/tests/rpc_common/mod.rs:21`, `api/tests/rpc_common/mod.rs:751`, `api/tests/rpc_common/mod.rs:776` | Test harness only (no external caller). |

| **Custody JSON** · Proposal payload hash key order | Hashed JSON payload keys in the arbitrary order sent by the client screen. | Sorts payload keys by name before computing payload hash; identical payloads with different key orders produce identical hashes. | Design §3 (#72) | `docs/design/xchange-v3.md:91`, `api/src/application/compat/v2_json.rs:20` | Caller submitting custody proposal with reordered JSON keys. |

| **Customer JSON** · Member fields pending D5 | Customer records carried `member` and `memberVerifiedAt` (source mechanism not in the recording). | `member` is always `false` and `memberVerifiedAt` is always `null` for every customer until the member/bookings decision (D5) is resolved. | Design §2 (D5), T11a (#143) | `api/src/application/compat/v2_json.rs:23-24` | Admin customer view. |

| **Snapshot** · Transaction status `COMPLETED` | Produced interim statuses `PENDING_FILES` or `ERROR` during file upload failures. | Files are uploaded prior to database transaction; save runs in a single DB transaction, so status is always `COMPLETED`. `PENDING_FILES` and `ERROR` are never produced. | Design §3 (#153), T11a (#143) | `docs/design/xchange-v3.md:85`, `api/src/application/compat/snapshot.rs:15-16` | Kept admin/desk screens (screens already handle their absence as error paths). |
| **Snapshot RPC** · `adminCreateBranch` sent again from MAIN | Refused with internal error sentence about table headers (`V2_HEADERS_FAULT`) because new branch tables were not loaded into the process. | Returns the new branch's snapshot directly (identical to calling from the new branch). | Ticket T11a (#143) | `api/src/application/compat/rpc.rs:34-36`, `api/tests/rpc_test.rs:587-590`, `api/tests/snapshot_test.rs:264-267` | Admin console re-sending branch creation from MAIN branch. |
| **Snapshot** · O(history) query and 10,000-row cap | Replayed entire ledger up to 10,000 rows (`server.mjs:6600`) to construct branch snapshot. | Assembles snapshot using SQL queries with a 10,000-row cap, keeping O(history) response size as intentional temporary debt until screen redesign. | Design §5.1 (`docs/design/xchange-v3.md:414-417`) | `docs/design/xchange-v3.md:414-417` | Kept admin and desk screens polling `adminSnapshot`. |
| **Custody** · Request validation precedence over branch state | Validated fields lazily during execution; when custody was disabled, answered "custody is not enabled" even for malformed bodies. | Rejects unparseable or malformed bodies with `คำขอไม่ถูกต้อง` before evaluating branch custody state. | **Custody** · Transfer note length limit checked at propose | Accepted transfer note at proposal time; failed during commit or reject when stock movement reason exceeded 200 units, stranding money in transit indefinitely (`v2_custody_service_cases.json` steps 78–82). | Refuses note at **proposal** time with shift sentence if formatted reason (`"<KIND> · " + note`) exceeds 200 UTF-16 units (max note length: 189 for `SAFE_OUT`, 186 for `EXTERNAL_IN`). | **Custody** · Unknown `ops…` action name refusal | Answered unknown `ops…` actions with errors dependent on branch state (#2 custody disabled, #23 not clocked in, #40 clocked in). | Unconditionally answers 400 `คำขอไม่ถูกต้อง` for any unrecognized `ops…` action name regardless of branch state. | Lane controller on T11a-C (#179) | `api/src/application/compat/actions/custody.rs:17-20`, `api/tests/rpc_ops_test.rs:27-32`, `api/tests/rpc_ops_test.rs:80-83` | API client sending unknown `ops...` actions. |
| **Kiosk** · Exact SELL quote foreign amount | Computed foreign currency amount from baht using binary float division, resulting in 1 cent less on exact hundredth midpoints (e.g. 14.67 baht at 32.60 yielded 0.44 for 14.34 baht; 12 of 219 recorded cases differed). | Computes exact foreign amount using decimal arithmetic (14.67 baht at 32.60 yields 0.45 for 14.67 baht). | Design §3 (#67) | `docs/design/xchange-v3.md:87`, `api/crates/xc-kiosk/tests/kiosk_service_common/mod.rs:1021` | Customer kiosk SELL quote display. |
| **Kiosk** · Refusal of `complete` without ID check | Silently linked saved document and left status in current state (QUOTED, WAITING, ACCEPTED). | Refuses completion with Thai domain error `คิวนี้ไม่พร้อมบันทึกหรือบันทึกแล้ว` if kiosk request is not in `ID_CHECKED` status. | Design §3 (#67) | `docs/design/xchange-v3.md:88`, `api/crates/xc-kiosk/tests/kiosk_service_common/mod.rs:1021` | Staff desk attempting to complete unverified kiosk quote. |
| **Kiosk** · Amount input format validation | Coerced user inputs via JavaScript type coercion, accepting negative numbers, exponential notation, spaces, or excessive decimals. | Strictly enforces plain decimal format with at most two decimal places; all invalid formats are rejected. | Design §3 (#67) | `docs/design/xchange-v3.md:89` | Kiosk user entering invalid amount format. |
| **Kiosk** · Expiration sweep branch lock scope | Kiosk expiration sweep purged quotes across all branches simultaneously. | Sweeps expired quotes only for the branch receiving a quote, under that branch's lock. | **Rates** · Decimal arithmetic on midpoint rates | Floating point calculations differed at exact half-cent midpoints. | Uses decimal arithmetic (`rust_decimal` / `NUMERIC(20,2)`); v2 stored values are retained, and recomputations report differences. | Design §2 (D2), §3 | `docs/design/xchange-v3.md:84` | Transaction receipt amounts at half-cent midpoints. |
| **Rates** · Bank of Thailand JPY reference rate division | Binary float division of BoT rate by 100 produced float artifacts (`20.9382 / 100` = `0.20938199999999998`). | Exact decimal division answers exact decimal text `0.209382`. | T5b (#89 / PR 95) | `api/crates/xc-rate/tests/bot_rate_source_test.rs:20-24` | Admin reference rates display for JPY. |
| **Auth** · Client IP address header resolution | Staff sign-in door prioritized `CF-Connecting-IP` over `X-Real-IP`. | Reads `X-Real-IP` exclusively across all doors (`CLIENT_ADDRESS_HEADER = "x-real-ip"`) and ignores `CF-Connecting-IP`.
